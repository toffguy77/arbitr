# 🚀 АРБИТРАЖНАЯ ТОРГОВАЯ СИСТЕМА - РУКОВОДСТВО ПО ЗАРАБОТКУ

## ⚠️ КРИТИЧНО: НАСТРОЙКА API КЛЮЧЕЙ

**БЕЗ РЕАЛЬНЫХ API КЛЮЧЕЙ СИСТЕМА НЕ БУДЕТ ТОРГОВАТЬ!**

1. Зайдите на https://www.bybit.com/app/user/api-management
2. Создайте новый API ключ с правами:
   - ✅ **Spot Trading** (ОБЯЗАТЕЛЬНО!)
   - ✅ **Read** 
   - ✅ **Trade**
3. Скопируйте API Key и Secret
4. Вставьте в `.env` файл:
   ```bash
   ARBITR_BYBIT_API_KEY=ваш_реальный_api_ключ
   ARBITR_BYBIT_SECRET=ваш_реальный_секрет
   ```

## ⚡ КРИТИЧЕСКИЕ ПРОВЕРКИ

### Перед запуском убедитесь:

- [ ] API ключи установлены в `.env`
- [ ] На Bybit есть баланс USDT/USDC
- [ ] Включены права Spot Trading
- [ ] Интернет соединение стабильное

### Признаки успешной работы:

- [ ] В логах появляются "starting triangle execution"
- [ ] Метрики показывают `arbitr_triangles_attempted_total` > 0
- [ ] Баланс на Bybit изменяется
- [ ] PnL растет

## 🔧 ДОПОЛНИТЕЛЬНАЯ ОПТИМИЗАЦИЯ

Для еще большего заработка можете:

1. **Увеличить баланс** - больше капитал = больше прибыль
2. **Добавить треугольники** в `config.yaml`
3. **Снизить `min_net_bps`** до 1-2 bps
4. **Увеличить `max_notional_usd`** до $5000+

## ⚠️ РИСКИ

- Высокая частота торговли = высокие комиссии
- Агрессивные настройки = больше риск
- Следите за PnL и останавливайте при убытках
